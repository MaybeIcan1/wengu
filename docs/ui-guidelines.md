# wengu UI 设计规范 v2

> 方向：**A 的排版骨架（列表+阅读、衬线标题、细线分隔）+ B 的暖色质感（奶油底、渐变主色、柔和阴影）**
> 落地位置：`frontend/src/style.css`（tokens 与 Element Plus 主题覆盖）。改主题只动这一个文件。
> 原型参考：`docs/ui-prototypes/A-editorial.png`、`B-soft.png`、`C-compact.png`

## 2. 字号阶梯（只用这几档）

`11 / 12 / 13 / 14 / 15 / 17 / 20 / 24 / 26`

- 页面标题：24（`serif`，字重 600）
- 阅读区标题：26（`serif`）
- 列表标题：15（600）
- 正文：13~14（行高 1.9~2）
- 辅助信息：11~12（`--ink-3`）

## 3. 间距 / 圆角 / 阴影

- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32
- 圆角：8（输入）/ 12（按钮、区块）/ 16（卡片）/ 999（胶囊）
- 阴影：`--shadow-sm`（默认）/ `--shadow-md`（悬浮）/ `--shadow-lg`（弹层）

## 4. 组件规则

**按钮**
- 文字必须水平垂直居中（全局已兜底：`.el-button` inline-flex 居中）
- 主按钮统一用品牌渐变（`.el-button--primary`），高度 38~42，字重 600
- 次按钮：白底 + `--line` 描边；文本按钮只用于低优先操作

**列表行**
- 行高 15px 标题 + 11px 元信息（标签用 `#tag` 文本，弱化颜色）
- 悬停底色 `#fffaf2`，操作按钮（编辑/删除）悬停才显示，避免噪音

**空状态**
- 必须区分两种：真空（引导 DIY / 导入）与筛选无结果（一键清除筛选）

**阅读区**
- 最大宽度 900，正文行高 2，代码块用暖灰底 `#f7f1e6`
- 引用块左侧 2px 品牌色竖线

## 5. 禁忌

- 不在页面里写死颜色/字号（全部走 token）
- 不新增第二套按钮样式（统一 `.el-button--primary`）
- 不用纯 emoji 当图标（用内联 SVG）
- 列表页不塞大段答案（MEDIUMTEXT 不进列表接口）
