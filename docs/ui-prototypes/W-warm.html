TCP 为什么握手要三次，挥手却要四次？

计算机网络#TCP#高频来源：牛客最后更新 10-20

三次握手是为了让双方都确认「自己的发送能力和对方的接收能力」都正常；四次挥手则是因为 TCP 是全双工，双方需要各自关闭发送通道。

握手的关键点

第三次握手不是多余的：它让服务端确认客户端确实收到了自己的 SYN-ACK，避免历史失效连接请求造成资源浪费。

Client Server | -------- SYN (seq=x) -------> | | <--- SYN+ACK (seq=y, ack=x+1) | | -------- ACK (ack=y+1) -----> |
记忆锚点：握手确认「双向可达」，挥手确认「双向关闭」——所以一个 3 步，一个 4 步。
