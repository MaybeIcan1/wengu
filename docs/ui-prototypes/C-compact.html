TCP 为什么握手要三次，挥手却要四次？

来源：牛客难度：中更新于 10-20

三次握手是为了让双方都确认「自己的发送能力和对方的接收能力」都正常；四次挥手则是因为 TCP 是全双工，双方需要各自关闭发送通道。

握手时序
Client Server | -------- SYN (seq=x) -------> | | <--- SYN+ACK (seq=y, ack=x+1) | | -------- ACK (ack=y+1) -----> |
为什么第三次握手不能省

它让服务端确认客户端确实收到了自己的 SYN-ACK，避免历史失效连接请求占用连接资源。
