# 00 · 课程导学

> 欢迎来到「wengu（温故）」项目实训课。本课程把一个大项目的完整开发过程拆成 **9 个实践章节（01~09）+ 结项章（10）**。
> 每一章都是一个可验收的里程碑，按顺序做完，你手里就是一个能写进简历的多用户全栈项目。

---

## 一、这门课怎么上（规则，先读 1 分钟）

1. **开章**：你说「开始 Phase N」→ 我先写好 `0N-xxx.md`（含数据库/后端/前端/测试四问 + 代码骨架），你读章再动手
2. **开发**：你按章内的骨架代码逐层实现（IDEA 图形界面优先）；终端命令（依赖安装/编译验证）由我执行
3. **答疑**：卡住把报错原文/截图+当前步骤发我，不走猜
4. **验收**：你按章末「验收清单」自查打勾 → 回「Phase N 完成」→ 我跑独立验收（含数据核对）→ 通过后把**实际落地的修正回写进该章**（课程与代码永远一致）
5. **收尾**：`git commit` 规范提交并 push，进下一章

## 二、项目的最终形态（学完你将拥有的东西）

**wengu（温故）——个人 DIY 面试知识库多用户平台**：

- 每个用户管理自己的八股/笔试题（题目-答案-标签-图片，Markdown 编辑）
- docx 一键批量导入（兼容既有文档格式，异步任务 + 进度推送）
- FSRS 科学方法复习（卡片翻转/随机问答/间隔重复）+ 签到打卡榜
- 每日配额系统（并发安全，秒杀同构）+ 多级缓存 + 全链路压测报告
- 手机浏览器/PWA 随时复习，可选打包安卓 APK
- AI 辅助制卡（本地大模型或 DeepSeek API）

## 五、每章统一模板（v2 纵切范式，2026-10-19 因用户反馈重构）

> **核心转变：从"模块漫游"到"纵切分层"**（此前按功能模块想到哪讲到哪，学起来吃力）：
> - 每章开头给 **「一条数据的完整旅程」**——这张请求从哪进、穿几层、每层结束系统能干什么，读者永远知道自己站在哪一层
> - 功能一律按**固定层序展开**：①规格定义（实体/表）→ ②数据层（Mapper/SQL）→ ③业务编排（Service 决策点）→ ④接口编排（Controller 路由/出入参）→ ⑤前端联调
> - 原有要素不丢，挂进对应层内：业务需求叙事（0️⃣层前置引入）、★必须理解标注（验收抽查）、结构动作三件（在哪/怎么建/为什么）、"我们缺什么"文件清单（各层开头）
> - 此前第 2/3 章是"模块式"旧范式，作为对照保留；觉得哪一处"漫游感"严重随时点名，我按纵切重排

```
🎯 本章目标与「我需要什么」    —— 清点前置：环境/知识/工具
🗄️ 数据库                      —— DDL 全文 + 每个设计的理由
⚙️ 后端                        —— 分层任务表（entity→mapper→service→controller）+ 代码骨架
🖥️ 前端                        —— 页面/组件/API 对接清单 + 骨架
🧪 测试与验收                  —— 用例表（Apifox）+ 验收清单（checkbox）
📦 本章交付物                  —— 产出文件清单 + git commit 规范
🔗 关联八股                    —— 本章代码对应的面试考点
下章预告
```
